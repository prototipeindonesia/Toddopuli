Kelola Data

Kelola data melalui panel ini

Daftar Pelatihan Tersedia

Pelatihan di bawah ini diselenggarakan oleh Admin/Super Admin TODDOPULI. Klik tombol Ikuti Pelatihan untuk mendaftar atau mengikuti pelatihan tersebut.

Sistem Persetujuan (ACC) — Data yang Anda input akan berstatus "Menunggu ACC" terlebih dahulu.

Admin/Super Admin akan menyetujui sebelum tampil di halaman utama. Anda tetap dapat melihat & mengedit data Anda sendiri.

Keterangan Status:

Menunggu ACC Belum disetujui — belum tampil di halaman utama.
Disetujui Sudah tampil di halaman utama.
Ditolak Tidak disetujui — periksa alasan & revisi.

Kalender Kegiatan

Agenda kegiatan TODDOPULI — kelola jadwal, reminder, dan export ke Google Calendar

Fitur Kalender Kegiatan: Admin/Super Admin dapat menambah, mengedit, dan menghapus kegiatan. Admin OPD & Masyarakat hanya dapat melihat.

Reminder otomatis muncul untuk kegiatan dalam 24 jam. Klik tombol untuk menambahkan ke Google Calendar pribadi Anda.

Edukasi HKI

Kelola artikel & video edukasi seputar Hak Kekayaan Intelektual

Konten edukasi akan tampil di halaman HKI di index.html. Tipe yang tersedia: Artikel (isi teks) dan Video (embed YouTube).

Permintaan Akses Download HKI

Permintaan dari pengunjung umum yang ingin mengunduh file HKI

Alur permintaan akses download HKI:

1. Pengunjung klik "Minta Akses Download" di halaman HKI
2. Isi nama, nomor WA, dan tujuan penggunaan
3. Admin cek & klik ACC untuk menyetujui
4. Kirim link download via Chat WA

Permintaan Akses Data

Permintaan download file Inovasi / Riset / Publikasi / Database dari pengunjung

Alur permintaan akses data (Inovasi, Riset, Publikasi, Database):

1. Pengunjung klik "Minta Akses Laporan/Dokumen" di halaman detail item
2. Isi nama, nomor WA, instansi, dan tujuan penggunaan
3. Admin cek & klik ACC untuk menyetujui
4. Kirim link download via Chat WA

Catatan: File dengan akses "Publik" tidak masuk ke sini — pengunjung langsung bisa download. Yang masuk hanya file dengan akses "Terbatas".

Pendaftaran Masyarakat Umum

Pendaftaran akun dari dosen, mahasiswa, pelajar, swasta, dan masyarakat umum

Alur Pembuatan Akun Masyarakat:

1. Masyarakat isi form pendaftaran di halaman utama
2. Admin/Super Admin cek di halaman ini
3. Klik "Buat Akun" → generate password otomatis
4. Kirim kredensial (email + password) via Chat WA
5. Masyarakat login & akses 4 menu: Dashboard, Inovasi, Riset, HKI, Pelatihan

Kelola Admin

Atur siapa saja yang bisa mengelola TODDOPULI

Role & Hak Akses

Super Admin Akses penuh — kelola semua data & admin lain + buat akun masyarakat.

Admin CRUD semua data (semua OPD) + approve/reject data Admin OPD & Masyarakat.

Admin OPD Hanya kelola data OPD sendiri. Menu terbatas: Dashboard, Inovasi, Riset, HKI, Pelatihan, Kalender, Galeri. Data perlu ACC Admin/Super Admin.

Masyarakat Umum Dosen, mahasiswa, pelajar, swasta. Menu terbatas: Dashboard, Inovasi, Riset, HKI, Pelatihan, Kalender. Data perlu ACC Admin/Super Admin.

Editor Hanya tambah & edit (tidak bisa hapus).

Alur Persetujuan (Approval):

1. Admin OPD / Masyarakat submit data Inovasi / Riset / HKI → status Menunggu ACC
2. Admin/Super Admin cek di menu terkait → klik tombol Setujui atau Tolak
3. Data yang disetujui baru akan tampil di halaman utama (index.html)
